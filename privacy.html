Privacy policy

Last updated: 12 November 2026

Atlas is a personal assistant used only by its owner. It is not available to other users.

What data Atlas accesses

With the owner's permission, Atlas uses Google APIs to read the owner's Gmail messages, Google Calendar events and Google Tasks. When the owner asks, it also creates Gmail drafts, calendar events and tasks. Atlas never sends email.

How the data is used and stored

Data is used only to give the owner summaries and reminders, and to create the drafts, events and tasks the owner asks for. It is processed on a private server controlled by the owner. It is not sold or shared with third parties, and it is not used for advertising.

Google API Services User Data Policy

Atlas's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

You can revoke access at any time at myaccount.google.com/permissions.
